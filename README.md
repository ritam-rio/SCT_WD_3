# 🎮 Tic-Tac-Toe Web Application

## 📌 Project Overview

This project is a **Tic-Tac-Toe Web Application** developed as part of the **SkillCraft Technology Web Development Internship (Task 3)**. It features a modern glassmorphism-inspired interface with smooth animations, responsive design, and an interactive two-player gameplay experience. The application automatically manages player turns, detects winning and draw conditions, and provides reset and new game functionality for continuous play.

---

## 🚀 Features

- Interactive 3×3 game board
- Two-player (Player vs Player) gameplay
- Automatic player turn switching
- Winner detection
- Draw game detection
- Winning cell highlight
- Reset Game functionality
- New Game option
- Responsive design
- Glassmorphism-inspired UI
- Smooth hover effects
- Modern animations
- Cross-browser compatibility

## 🎮 Game Rules

| Rule | Description |
|------|-------------|
| First Player | Player **O** starts the game |
| Turns | Players take turns placing **O** and **X** |
| Winning Condition | Match three identical symbols horizontally, vertically, or diagonally |
| Draw Condition | All cells are filled without a winner |
| Restart | Use **Reset Game** or **New Game** to play again |
