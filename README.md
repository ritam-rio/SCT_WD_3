# 🎮 Tic-Tac-Toe Web Application

## 📌 Project Overview

This project is a **Tic-Tac-Toe Web Application** developed as part of the **SkillCraft Technology Web Development Internship (Task 3)**. It features a modern glassmorphism-inspired interface with smooth animations, responsive design, and supports both **Player vs Player** and **Player vs Computer** game modes. The computer opponent offers **Medium** and **Hard** difficulty levels, with Hard mode powered by the **Minimax Algorithm** for intelligent gameplay. The application automatically manages player turns, detects winning and draw conditions, highlights the winning combination, and provides Reset and New Game functionality for an engaging gaming experience.

## 🚀 Features

- Interactive 3×3 game board

- Hard AI difficulty (Minimax Algorithm)

## 🎮 Game Modes

| Mode | Description |
|------|-------------|
| Player vs Player | Two players compete on the same device |
| Player vs Computer | Play against an AI opponent |
| Medium AI | Makes strategic moves with basic decision-making |
| Hard AI | Uses the Minimax Algorithm for near-optimal gameplay |

---

## 🎯 Game Rules

| Rule | Description |
|------|-------------|
| First Player | Player **O** always starts the game |
| Turns | Players take turns placing **O** and **X** |
| Winning Condition | Match three identical symbols horizontally, vertically, or diagonally |
| Draw Condition | Fill all nine cells without a winner |
| Restart | Use **Reset Game** or **New Game** to play again |
